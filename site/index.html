Second Brain is a persistent memory layer that plugs into any LLM — local llama.cpp, Claude, Codex, GPT, Gemini, Grok, Ollama — through MCP connectors. Everything it learns is plain Markdown in a private GitHub repo you own: swap models anytime, your knowledge stays. Runs on your machine, a VPS, or a bot's VM.

should actually do.

🧠

Tiered memory

Short, medium and long-term memory — like a real brain. Nightly "sleep" cycles review the day and distill facts, lessons and skills.

🤖

Specialist agents

Chat with Buffett, Gates, Musk, Naval and Jobs personas — or build your own. They answer with your full memory context.

🗣️

Agent meetings

Convene a roundtable on any topic. They debate live, reach consensus, and action items land straight in your task list.

📅

Today command center

Daily intentions, tasks with due dates, quick notes — one screen that opens every morning.

⚡

Natural automations

"Every day at 8am summarize my WhatsApp" becomes a scheduled cron. Daily, interval or weekly — pause, resume, run now.

🧮

Local semantic search

Optional RAG embeddings (BGE/Nomic via llama.cpp) give the brain meaning-based recall — fully offline.

🔌

MCP connectors

Any MCP server over stdio — WhatsApp via QR, Telegram bot and Postgres bundled, plus whatever you add. LLMs call them as native tools.

🔀

LLM-agnostic

Bundled local llama.cpp, Codex/ChatGPT sign-in, Claude Pro/Max, OpenAI, Gemini, Grok, Ollama. Swap the runtime — keep the brain.

📦

Knowledge outlives models

Memory is Markdown in your repo, not weights in a provider. Retire GPT-4, adopt the next model — nothing is forgotten.

🖥️

Runs anywhere

Desktop app on macOS/Windows/Linux — or install it on a VPS, or let a bot (Grok, Claude, yours) set it up on its own VM and wake up with persistent memory.

🔐

Local accounts + Google

SQLite auth with scrypt hashing, Google sign-in via PKCE. Your data never leaves your machine unless you want it to.

🔄

Auto-updates

Built-in updater checks GitHub Releases on launch. New versions install themselves in the background.

The repo is the brain.
LLMs are just runtimes.

Every note, insight, task and meeting is a plain Markdown file in a private repo only you control — synced both ways, before every chat. That's what makes Second Brain LLM-independent: Claude writes today, Grok answers tomorrow, a local model runs offline next week. Same memory, any engine. A GitHub repo is the one thing every LLM workflow already has.
